# S-Sim 데이터 팩

S-Sim이 제공·관리하는 데이터를 지역별로 묶은 폴더이다. 플러그인의 지역 설정 페이지에서 데이터 팩 위치를 지정하고 지역을 고른 뒤 [지역 적용]을 누르면, 각 파트의 공통 입력이 이 폴더에서 자동으로 채워진다. 가이드라인상 사용자가 준비하는 자료인 도로망과 통행 행렬은 지역 폴더의 `07_사용자자료`에 따로 둔다.

## 폴더 구조

```
S-Sim_데이터팩/
├─ README.md
└─ 지역/
   └─ 전남광주통합특별시/
      ├─ region.json                         지역 정의와 파일·필드 목록
      ├─ 00_경계/행정경계.gpkg               계획권역 · 시군구(27) · 읍면동(394)
      ├─ 01_격자/거점지도격자_2023.gpkg      1km 격자 16,113개
      ├─ 02_생활인프라/                       500m 충족여부 · 1km 요약 · 20종 메타데이터
      ├─ 03_인구추계/                         거주인구 추계 · 15세 이상 장래인구 · 고용률 · 실측 근무인구
      ├─ 04_개발사업/개발사업.gpkg
      ├─ 05_시설/근린시설 · 거점시설          각 5종
      ├─ 06_탄소/탄소총배출_격자_2023.csv
      └─ 07_사용자자료/                       도로망(KTDB 정제본) · 1km 격자 통행 행렬
   └─ 순천시/                                 전남광주통합특별시에서 순천시(36030)만 추출 (2026-10-23)
      ├─ region.json                         unit=시군구, 강소도시·성숙·안정형
      ├─ 00_경계/행정경계.gpkg               계획권역 · 시군구(1) · 읍면동(24)
      ├─ 01_격자/거점지도격자_2023.gpkg      1km 격자 921개
      ├─ 02_생활인프라/                       500m 3,648셀 · 1km 921셀 · 20종 메타데이터
      ├─ 03_인구추계/                         거주인구 추계(통계청 · 2040 순천도시기본계획 계획인구) · 15세 이상 장래인구 · 고용률 · 실측 근무인구
      ├─ 04_개발사업/개발사업.gpkg            25건
      ├─ 05_시설/근린시설 · 거점시설          순천시 경계 안 1,106개
      ├─ 06_탄소/탄소총배출_격자_2023.csv
      └─ 07_사용자자료/                       1km 격자 통행 행렬(순천 내부). 도로망은 복사하지 않고
                                              region.json에서 ../전남광주통합특별시/07_사용자자료/도로망_KTDB_2023.gpkg 를 가리킴
```

- 순천시 도로망은 시 경계에서 끊지 않도록 전남광주통합특별시의 파일을 그대로 쓴다. 따라서 두 지역 폴더는 같은 `지역/` 아래에 함께 두어야 한다.

## region.json

| 항목 | 의미 |
|---|---|
| `name` | 지역명. 대시보드 제목과 결과 폴더 이름에 쓰인다. |
| `unit` | 지역 위계. `시도`이면 내부 구분 경계는 시군구, `시군구`이면 읍면동이다. |
| `sgg_codes` | 계획권역을 이루는 시군구 코드 목록. |
| `base_year` | 기준연도. |
| `city_type` · `trend_type` | 가이드라인 참조값(표4·표7·표8)에 쓰는 도시위상과 인구추세 유형. |
| `sgg_city_type` · `sgg_trend_type` | 시군구별 도시위상과 인구추세 유형(가이드라인 부표1·부표2). |
| `data` | 자료별 상대 경로와 필드 이름. |
| `user_inputs` | 사용자 준비 자료(도로망·통행 행렬)의 경로와 필드. 파일이 있으면 [지역 적용] 때 함께 채워지고, 지역 설정 페이지에서 다른 파일을 지정하면 그것이 우선한다. |
| `sources` | 자료 출처와 시점. |

## 외부 배포 시 유의

`07_사용자자료`의 통행 행렬은 통신사 자료이고 도로망은 KTDB 원자료를 정제한 것이다. 데이터 팩을 외부에 배포할 때는 이 폴더를 빼고, 사용자가 자기 자료를 지역 설정 페이지에서 지정하게 한다.

## 데이터 팩에 넣지 않는 자료

- S-Sim이 실행 중에 만드는 자료: 중심지 위계, 중심지 중심점, 격자→중심지 OD, 생활권 경계, 시나리오별 장래 격자인구. 이들은 사용자가 지정한 결과 폴더에 저장된다.

## 지역 추가

`지역/` 아래에 지역명 폴더를 만들고 같은 하위 구조와 `region.json`을 둔다. 청주시처럼 시 단위 권역은 `unit`을 `시군구`로 적고, `sgg_codes`에 구 코드(33041–33044)를 모두 넣는다.

## 자료 시점

격자와 탄소는 2023년, 읍면동 경계는 2023년 4분기(기준연도), 시군구 경계는 2025년 2분기, 생활인프라 충족도는 2022년 기준이다. 광주·전남의 시군구 코드는 두 시점 사이에 바뀌지 않았다.
