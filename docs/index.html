인구 배분 ①

BAU 배분 — 현상 유지 시나리오

INPUT
공통 데이터의 격자 + 추계 테이블 (추가 입력 없음)
→
알고리즘
pop(g,y) = P(s,y) × w(g)/Σw · w = 기준연도 격자인구 — 분포 고정, 총량만 증감
→
OUTPUT
연도별 배분 인구가 담긴 격자 자료 → 연도별 단계구분도 그룹 + 3D 슬롯 자동 연결
  • 1결과 저장 파일 — 비워두면 분석결과\거주인구배분\에 자동 저장
  • 2실행 — 공통 데이터만 있으면 바로. 옆 [산식 보기]에 위 수식
  • 가중치 합 0인 시군구(인구 전무)는 균등 배분 + 경고.
  • 지도 그룹은 연도별 레이어(0·100·200·500·1000·5000 고정 구간) — 마지막 연도만 켜짐.
  • 역할: "지금 많은 곳이 미래에도 많다"는 관성 기준선 — 거점유도·계획인구와 비교용.
검증 실행 후 시군구별 pop_YYYY 합계가 추계 테이블과 일치하는지 확인 — 모든 배분 공통.

거점유도 배분 — 정책관심구역 + 지수모형

INPUT
공통 데이터 + 거점 정의 자료 (생활인프라 충족도 또는 기존 거점 목록)
→
알고리즘
거점 = 유형 ∪ 충족도 → w = ratio^지수 (거점 a·b, 비거점 c·d) 연도 연쇄
→
OUTPUT
정책관심구역 + 거점유도 배분 격자 자료 → 지도 그룹(거점 경계 포함)
  • 1정책관심구역 파일 — 기존 거점 격자 파일이 있으면 여기에 직접 (gid만 매칭)
  • 2생활인프라 파일 — 새로 산출할 때. 거점 유형 체크 + 충족도 기준(마을 Me_CI_1 ≥ 3 · 거점 Me_CI_2 ≥ 3)과 합집합
  • 3정책관심구역 산출 — 결과가 1에 자동 연결
  • 4지수 계수 — 기본값 a 1.1 · b 0.9 · c 0.9 · d 1.1. 1에 가까울수록 BAU에 수렴
  • 5결과 저장 파일 · 6배분 실행
ratio(g) = 직전 시점 격자인구 ÷ 시군구 평균 → w(g) = ratio^지수 → 비례 배분 a: 인구 많은 거점 집중 강화 · b: 적은 거점 감소 완화 · c: 많은 비거점 억제 · d: 적은 비거점 감소 강화 — 결과가 다음 연도 ratio로 연쇄

INPUT

  • 4추계 CSV 저장 파일 · 5실행 — 완료 시 자동 연결 + ① BAU로 이동
취업자(y) = 고용률(y) × 15세 이상 인구(y) → 근무인구(t₁) = 근무인구(직전) × (1+g)^년수
  • 공통 데이터에서 격자를 먼저 선택해야 실행 가능 (앵커 산출용).
  • 계획인구 반영 시 개발지구 근무 유입 = 계획인구 × 시군 원단위(Σpop_w/Σpop_r).
