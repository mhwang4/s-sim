INPUT

거점유도 배분 - 정책관심구역 + 지수모형

INPUT
공통 데이터 + 거점 정의 자료 (생활인프라 충족도 또는 기존 거점 목록)
→
알고리즘
거점 = 유형 ∪ 충족도 → w = ratio^지수 (거점 a·b, 비거점 c·d) 연도 연쇄
→
OUTPUT
정책관심구역 + 거점유도 배분 격자 자료 → 지도 그룹(거점 경계 포함)
  • 1정책관심구역 파일 - 기존 거점 격자 파일이 있으면 여기에 직접 (gid만 매칭)
  • 2새로 산출 - 거점 유형 체크 + 충족도 기준(마을 Me_CI_1 ≥ 3 · 거점 Me_CI_2 ≥ 3)과 합집합. 생활인프라 파일은 지역 적용 시 자동 입력
  • 3정책관심구역 산출 - 결과가 1에 자동 연결
  • 4지수 계수 - 기본값 a 1.1 · b 0.9 · c 0.9 · d 1.1 - 1에 가까울수록 BAU에 수렴
  • 5결과 저장 파일 · 6배분 실행
ratio(g) = 직전 시점 격자인구 ÷ 시군구 평균 → w(g) = ratio^지수 → 비례 배분 a: 인구 많은 거점 집중 강화 · b: 적은 거점 감소 완화 · c: 많은 비거점 억제 · d: 적은 비거점 감소 강화 - 결과가 다음 연도 ratio로 연쇄
