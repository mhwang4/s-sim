# 입력자료(데이터팩)와 결과 폴더

## 1. S-Sim 데이터팩

```
S-Sim_데이터팩/
└─ 지역/
   └─ (지역명)/
      ├─ region.json                    지역 정의, 자료별 경로·필드, 도시위상·인구추세
      ├─ 00_경계/행정경계.gpkg           계획권역 · 시군구 · 읍면동
      ├─ 01_격자/거점지도격자_2023.gpkg  1km 격자 (gid, sgg_cd, sgg_cd_h, pop_r, pop_w, pc_in, pc_out, type)
      ├─ 02_생활인프라/                  충족여부 500m · 1km 요약
      ├─ 03_인구추계/                    거주인구 추계(시군구) · 15세 이상 장래인구 · 고용률 · 실측 근무인구
      ├─ 04_개발사업/개발사업.gpkg       plan_pop, yr_done, prj_pop, sgg_cd_h, PLAN_EMP
      ├─ 05_시설/근린시설 · 거점시설      시설 점 자료(유형별 파일)
      ├─ 06_탄소/탄소총배출_격자_2023.csv grid_cd, exhst_vl
      └─ 07_사용자자료/                  도로망(KTDB 정제본, ONEWAY) · 1km 격자 통행 행렬
```

- 모든 자료는 EPSG:5179(미터 단위 투영좌표계)여야 한다. 위경도 좌표계 파일은 실행 전에 거부된다.
- `07_사용자자료`는 가이드라인상 사용자가 준비하는 자료다. 통행 행렬(통신사)·도로망(KTDB 정제본)은 외부 배포 시 빼고 사용자가 자기 자료를 지정한다.
- 지역을 추가하려면 `지역/` 아래에 같은 구조와 region.json을 둔다. 시 단위 권역은 `unit`을 `시군구`로 적는다.
- 지역별 실제 경로와 존재 여부는 MCP `list_regions`로 확인한다.

## 2. 결과 폴더

`결과 저장 폴더\S-Sim_분석결과(지역명)\` 아래에 메뉴와 같은 구성으로 저장된다.

```
S-Sim_분석결과(지역명)/
├─ 장래인구 격자 배분 및 중심지 전망/
│  ├─ 거주인구 배분/   거주배분_1_BAU · _2_거점유도 · _3_계획인구.gpkg, 정책관심구역.gpkg
│  │  └─ 시나리오별_장래인구/{BAU · 유도정책 · 계획반영}/(지역명)_(유형)_(연도).shp  (pop_tot, pop_w)
│  ├─ 근무인구 배분/   근무배분_1_BAU · _2_계획반영.gpkg, 추계_근무인구.csv
│  ├─ 장래 중심지 전망/ 중심지_식별.gpkg, 중심지_요약.csv
│  └─ 인구배분_3D.html
├─ 중심지 및 생활권 분석/
│  ├─ 중심지 분석/     중심지후보_*.gpkg, 중심지_속성, 중심지_위계.gpkg (tier: 1차중심지·2차중심지·3차중심지)
│  └─ 생활권 분석/     중심지_중심점, 격자_중심지_OD.csv, 기초생활권_할당·스무딩·권역,
│                      중심지_대표점, 중심지_거리행렬, 매력도_점수·이동량(1차·2차),
│                      상위생활권_2차중심지권역 · 상위생활권_1차중심지권역.gpkg (zone_nm)
└─ KPI 지표 계산/
   ├─ 기초통계 · 콤팩트성 · 네트워크성 · 생활편리성 _결과.csv / _결과.json
   └─ 공간구조_진단_대시보드.html   (진단 요약 탭에 가이드라인 표9·표10 형식 표, 머리의 [성과 평가 지원] 창 — guide('kpi') §6)
```

- MCP로 실행한 결과는 `mcp_server\분석결과\` 아래에 모인다. `run_pipeline`·`run_kpi`는 `S-Sim_분석결과(지역명)\`에 위와 같은 구성으로, `run_algorithm`에서 출력 경로를 생략한 개별 실행은 `MCP_실행결과\`에 저장되며, 실행 이력(`run_log.jsonl`)과 작업 기록(`작업기록\`)도 `MCP_실행결과\`에 남는다.
- KPI는 `상위생활권_1차중심지권역.gpkg`(최상위 생활권)와 `중심지_위계.gpkg`가 있어야 하며, 장래 전망은 `시나리오별_장래인구`, 접근 형평성은 `격자_중심지_OD.csv`가 있을 때 산출된다.
