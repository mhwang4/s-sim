# S-Sim 분석 흐름

S-Sim(KRIHS Spatial Structure Simulation)은 인구감소를 고려한 공간구조 진단·전망 가이드라인의 분석을 수행하는 QGIS 플러그인이다. 플러그인 화면의 좌측 메뉴 순서가 분석 순서이며, 각 단계의 결과는 다음 단계의 입력으로 자동 연결된다. MCP에서는 `run_pipeline`이 이 흐름 전체(또는 고른 단계 `population`·`future_centers`·`centers_zones`·`kpi`·`viz`)를 플러그인과 같은 기본값·연결로 실행하고, `job_status`로 진행을 확인한다. 알고리즘 하나만 따로 돌릴 때는 `run_algorithm`을 쓴다.

## 0. 분석 지역 설정

데이터팩 폴더, 지역, 결과 저장 폴더를 지정하면 모든 단계의 공통 입력이 데이터팩에서 채워지고, 결과는 `결과 저장 폴더\S-Sim_분석결과(지역명)\`에 모인다. MCP에서는 `list_regions`가 같은 정보를 돌려준다.

## 1. 장래인구 격자 배분 및 중심지 전망

| 메뉴 | 알고리즘 id | 내용 |
|---|---|---|
| 거주 ① BAU 배분 | `bau_grid_allocate` | 기준연도 격자별 인구 비율을 유지하여 시·군 추계인구를 격자에 배분 |
| 거주 ② 거점유도 배분 | `policy_interest_area` → `hub_grid_allocate` | 정책관심구역(거점 유형 ∪ 생활인프라 충족도)을 정한 뒤 거점에 인구를 더 배분 |
| 거주 ③ 계획인구 반영 배분 | `plan_grid_allocate` | 개발사업 지구의 계획인구를 준공연도에 따라 반영 |
| 근무 장래 추계·①·② | (화면 기능) · `bau_grid_allocate` · `plan_grid_allocate` | 고용률 연평균 증감률 × 15세 이상 장래인구로 시·군 근무인구를 추정한 뒤 격자 배분 |
| 장래 중심지 식별 | `center_identify` | 장래 거주·근무 격자로 연도별 중심지와 위계 산출 |

거주 배분 결과는 `시나리오별_장래인구\{BAU·유도정책·계획반영}\`에 연도별 파일(주거 pop_tot, 근무 pop_w)로도 저장되며, KPI 장래 전망이 이를 읽는다.

## 2. 중심지 및 생활권 분석

| 메뉴 | 알고리즘 id | 내용 |
|---|---|---|
| ① 중심지 추출 및 위계 분류 | `extract_candidates` → `extract_center_attributes` → `classify_centers` | 최소 주거인구 밀도로 후보 추출 → 후보 속성 집계 → 표4·표5 기준으로 1·2·3차 위계 |
| ② 중심지 중심점 생성 | `center_grid_points` | 중심지에 속한 격자 중심점 |
| ③ 격자-중심지 OD 행렬 산출 | `grid_center_od_scipy_graph` | 도로망 최단거리(격자 → 중심지) |
| ④ 3차중심지 권역 도출 | `od_matrix_region_assign` → `region_smoothing` | 격자를 비용 최소 중심지에 할당 후 스무딩 → 기초생활권 |
| ⑤ 상위생활권 도출 | `pop_weighted_centroid` → `od_matrix_road_distance_scipy` → `attractiveness_upper_zone` (`mobility_matrix` 부산물) | 매력도 = (유입통행 + 유출통행) ÷ 거리² 로 하위 생활권을 상위 중심지에 배정, 2차 권역 → 1차 권역(최상위 생활권) |

## 3. KPI 지표 계산

공통 데이터(격자, 최상위 생활권, 중심지 위계, 행정경계, 도로망, 격자-중심지 OD, 탄소, 시설, 시나리오별 장래인구)를 연결한 뒤 일괄 산출하면 ①기초통계 ②콤팩트성 ③네트워크성 ④생활편리성 결과(CSV·JSON)와 종합 리포트(HTML)가 만들어진다. 알고리즘 id는 `spatial_structure_indicators_kpi`이며, MCP의 `run_kpi`가 입력을 자동으로 채운다.

## 4. 3D 시각화

배분 결과와 중심지 식별 결과를 deck.gl 3D 지도(HTML)로 본다(화면 기능).
