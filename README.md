# S-Sim — 공간구조 시뮬레이션 분석도구 (KRIHS)

Spatial structure Simulator QGIS Plugin by KRIHS.
「인구감소를 고려한 공간구조 진단·전망 가이드라인」의 분석을 수행하는 QGIS 플러그인, 지역 데이터팩, MCP 서버를 한 저장소에 담았다.

- 플러그인 코드·데이터팩·MCP 서버는 이 저장소에서 계속 갱신한다.
- 이전 버전(인구배분·중심지 식별 통합 도구 `krihs_popalloc_tools` v1.7.0)을 이어받아 통합·확장한 것이다.

## 폴더 구성

```
s-sim\
├── 설치.bat                 ← 플러그인을 QGIS 기본 프로필에 복사 (더블클릭)
├── README.md                ← 이 문서
├── KRIHS_S_Sim\             ← QGIS 플러그인 본체 (v1.0.0, 알고리즘 17종)
│   ├── cnt_classifier\          중심지 추출·위계 분류, 상위생활권 알고리즘
│   ├── od_to_region\            기초생활권(3차중심지 권역) 알고리즘
│   ├── alg_*.py                 장래인구 배분·장래 중심지 식별·OD(scipy)·KPI 지표
│   └── data\                    과거 격자 인구(2000~), 시도 경계 삽도
├── mcp_server\              ← MCP 서버 (Claude에서 대화로 분석 실행 — 설치법은 mcp_server\README.md)
│   └── guide\                   도움말: 분석 흐름 / 중심지·생활권 기준 / KPI 지표와 해석 / 입력자료·결과 폴더
└── S-Sim_데이터팩\          ← 지역별 공통 입력 (지역을 고르면 모든 단계 입력이 자동 연결)
    └── 지역\전남광주통합특별시\
        ├── region.json          지역 정의, 파일·필드 목록, 도시위상·인구추세 유형
        ├── 00_경계\             계획권역·시군구(27)·읍면동(394)  ※ Git LFS
        ├── 01_격자\             국토공간거점지도 1km 격자 (2023)
        ├── 02_생활인프라\        생활인프라 충족도 500m·1km, 20종 메타데이터
        ├── 03_인구추계\          거주인구 추계(통계청·계획인구), 15세 이상 장래인구, 고용률, 실측 근무인구
        ├── 04_개발사업\
        ├── 05_시설\             근린시설 5종 · 거점시설 5종
        ├── 06_탄소\             격자 탄소 총배출 (2023)
        └── 07_사용자자료\        도로망(KTDB 2023 정제본), 1km 격자 통근 통행 행렬
    └── 지역\순천시\              전남광주통합특별시에서 순천시만 추출 (같은 하위 구조)
        └── 07_사용자자료\        통행 행렬(순천 내부). 도로망은 전남광주 파일을 상대경로로 참조
```

## 플러그인 좌측 메뉴 구조

```
분석 지역 설정        데이터팩 · 결과 폴더 → [지역 적용]으로 전 단계 입력 자동 연결
장래인구 격자 배분 및 중심지 전망
  거주인구 배분       공통 데이터 / ① BAU / ② 거점(정책관심구역) 유도 / ③ 계획인구 반영
  근무인구 배분       공통 데이터 / 장래 근무인구 추계(시·군) / ① BAU / ② 계획인구 반영
  장래 중심지 전망     장래 중심지 식별 (주거·근무 인구 기준, 1·2·3차 위계)
중심지-생활권 분석
  공통 데이터
  ① 중심지 추출 및 위계 분류    후보 추출 → 속성 집계 → 위계 설정 (표4·표5 기준)
  ② 중심지 중심점 생성
  ③ 격자-중심지 OD 행렬 산출    도로망 최단거리 (QGIS 내장 scipy)
  ④ 3차중심지 권역 도출         최소비용 배정 → 스무딩
  ⑤ 상위생활권 도출             인구가중 대표점 → 중심지 간 거리 → 통행 매력도 배정
KPI 지표 계산         공통 데이터 / 일괄 산출 / ① 기초통계 / ② 콤팩트성 / ③ 네트워크성 / ④ 생활편리성
종합 리포트 생성       종합 리포트 (HTML: 진단 요약·계획권역·생활권별·지역 과거 현황·성과 평가 지원)
시각화                3D 시각화 (deck.gl HTML)
데이터 탐색            기초 통계 탐색
```

- 각 입력 칸의 [형식] 버튼 = 필요한 필드와 예시, 실행 버튼 옆 [산식 보기] = 계산 방식
- 단계가 끝나면 ✓ 표시와 함께 다음 단계로 이동하고, 결과는 다음 단계 입력에 자동 연결
- 결과는 `결과 저장 폴더\S-Sim_분석결과(지역명)\`에 메뉴와 같은 구성으로 저장
- Processing 툴박스에도 17개 알고리즘이 개별 등록됨 (세부 파라미터 조정용)

## 설치·요구사항

1. QGIS를 종료한 상태에서 `설치.bat` 실행 → QGIS 실행 → [플러그인 → 플러그인 관리 및 설치]에서 **KRIHS S-Sim** 활성화
2. 툴바의 S-Sim 아이콘으로 창을 열고, **분석 지역 설정**에서 `S-Sim_데이터팩` 폴더·지역·결과 저장 폴더를 지정한 뒤 [지역 적용]
3. 좌측 메뉴 순서대로 실행

- Windows, QGIS 3.16 이상 (LTR 권장, 3.44에서 검증)
- 추가 QGIS 플러그인 불필요 — 도로망 거리 계산은 QGIS에 포함된 scipy 사용 (이전 버전의 QNEAT3 의존 제거)
- 데이터팩의 `행정경계.gpkg`(127MB)는 Git LFS로 저장되어 있음. clone하면 함께 받아지며, 파일이 1KB 남짓한 텍스트로 받아졌다면 `git lfs pull` 실행

## MCP 서버 (Claude에서 분석 실행)

`mcp_server\`는 플러그인의 분석 기능을 MCP(Model Context Protocol) 서버로 노출한다. Claude Desktop·Claude Code에 등록하면 대화로 분석을 실행할 수 있다. QGIS 엔진이 화면 없이(headless) 내 PC에서 돌며, 데이터와 연산은 PC 밖으로 나가지 않는다. 플러그인과 같은 알고리즘·데이터팩·결과 폴더 구성을 쓰므로 결과도 같다.

### 설치 방법

QGIS·Claude Desktop 설치 → 플러그인 설치(`설치.bat`) → `mcp_server\설치_mcp.bat` 더블클릭 → Claude Desktop을 트레이까지 완전히 종료 후 재시작.
Claude Code는 아래 명령으로 등록한 뒤 새 세션을 연다.

```
claude mcp add -s user krihs-s-sim -- cmd /c "(이 저장소 경로)\mcp_server\run_server.bat"
```

상세 안내·문제 해결은 `mcp_server\README.md` 참조.

### 사용 가능한 기능 (MCP tool)

| tool | 기능 |
|---|---|
| `check_environment` | QGIS·플러그인 버전, 알고리즘 수, 데이터팩 위치·지역, 결과 저장 위치 점검 |
| `list_regions` | 데이터팩의 지역 목록, 지역별 입력 파일 존재 여부, 이미 만든 분석 결과 |
| `list_algorithms` | 알고리즘 17종 목록 (id·이름·그룹) |
| `describe_algorithm` | 알고리즘 1개의 파라미터 명세 |
| `run_algorithm` | 알고리즘 1개 실행 (17종 전부) — 입력 사전 검사, 결과 요약, 실행 이력 |
| `run_pipeline` | 플러그인 전체 흐름을 메뉴 순서대로 실행 — 장래인구 배분 → 장래 중심지 식별 → 중심지·생활권 ①~⑤ → KPI 일괄 산출·리포트 → 3D (단계 선택 가능, 약 15분) |
| `run_kpi` | KPI 산출(일괄 또는 단계) + 종합 리포트 |
| `job_status` / `cancel_job` | `run_pipeline`·`run_kpi` 작업의 진행 확인 / 중지 |
| `guide` | 도움말 — 분석 흐름, 중심지·생활권 기준(표1~표5), KPI 지표와 해석(표6~표8), 입력자료·결과 폴더 |

### 데이터 규약

- 데이터팩: 저장소의 `S-Sim_데이터팩\`을 자동으로 사용 (다른 위치면 환경변수 `S_SIM_DATAPACK`)
- 결과: `mcp_server\분석결과\`에 저장 (처음 실행할 때 생김, git 제외)
  - `S-Sim_분석결과(지역명)\` — `run_pipeline`·`run_kpi` 결과 (플러그인과 같은 구성)
  - `MCP_실행결과\` — `run_algorithm` 개별 출력, `run_log.jsonl`(실행 이력)
- 입력 경로는 절대경로 또는 파일명만 써도 데이터팩·결과 폴더에서 찾아 실행
- 입력이 위경도 좌표계면 실행을 거부하고 변환 방법을 안내. 실패 시 원인·로그·확인 항목을 한국어로 반환

## 자료 이용 시 유의

- `07_사용자자료`의 통행 행렬은 통신사 자료, 도로망은 KTDB 원자료 정제본이다. 가이드라인상 사용자가 준비하는 자료이므로, 다른 지역에 적용할 때는 사용자 자료를 같은 형식으로 지정한다.
- 생활편리성 KPI의 서비스권 반경·관리 대상 최소 배후인구 기본값(근린 1.5km·500명, 거점 3km·3,000명)은 예시 산출용 값이다. 플러그인 KPI 공통 데이터에서 바꿀 수 있다.
- 플러그인을 고친 경우 이 저장소의 `KRIHS_S_Sim`과 QGIS에 설치된 플러그인을 함께 바꾼다(`설치.bat` 재실행). MCP 서버는 저장소 안의 플러그인을 쓴다.
