# KRIHS S-Sim — 공간구조 시뮬레이션 분석도구

인구감소를 고려한 공간구조 진단·전망 가이드라인의 분석을 수행하는 QGIS 플러그인과 데이터, MCP 서버를 한데 묶은 배포본이다.

- **플러그인(KRIHS S-Sim)**: QGIS 화면에서 메뉴를 따라 분석한다. 장래인구 격자 배분, 장래 중심지 전망, 중심지·생활권 분석, 공간구조 KPI 진단과 종합 리포트, 3D 시각화.
- **데이터팩**: 지역별 공통 입력 자료. 지역을 고르면 모든 단계의 입력이 자동으로 채워진다.
- **MCP 서버(선택)**: 같은 분석을 Claude(Desktop·Code)에게 대화로 시킨다.

## 구성

```
S-Sim\
├── 설치.bat             플러그인을 QGIS에 설치 (더블클릭)
├── README.md            이 문서
├── KRIHS_S_Sim\         QGIS 플러그인 본체
├── S-Sim_데이터팩\       지역별 공통 입력 (README.md 참조)
│   └── 지역\전남광주통합특별시\  region.json, 경계·격자·생활인프라·인구추계·개발사업·시설·탄소·사용자자료
└── mcp_server\          MCP 서버 (README.md 참조)
    └── guide\           도움말: 분석 흐름, 중심지·생활권 기준, KPI 지표와 해석, 입력자료·결과 폴더
```

## 요구사항

- Windows, QGIS 3.16 이상(LTR 권장, 3.44에서 검증)
- 추가 QGIS 플러그인은 필요 없다(도로망 거리 계산은 QGIS에 포함된 scipy로 한다).
- MCP를 쓸 때만: Claude Desktop 또는 Claude Code, 설치 시 인터넷 연결

## 설치와 사용

1. QGIS를 종료한 상태에서 `설치.bat`을 실행한다.
2. QGIS를 실행하고 [플러그인 → 플러그인 관리 및 설치]에서 **KRIHS S-Sim**을 활성화한다.
3. 툴바의 S-Sim 아이콘으로 창을 연다.
4. **분석 지역 설정**에서 데이터팩 폴더(`S-Sim_데이터팩`), 지역, 결과 저장 폴더를 지정하고 [지역 적용]을 누른다.
5. 좌측 메뉴 순서대로 실행한다. 각 단계의 결과는 다음 단계 입력으로 자동 연결되고, 결과는 `결과 저장 폴더\S-Sim_분석결과(지역명)\`에 메뉴와 같은 구성으로 모인다.
   - 장래인구 격자 배분 및 중심지 전망 (거주·근무인구 배분, 장래 중심지 식별)
   - 중심지 및 생활권 분석 (① 중심지 추출 및 위계 분류 ~ ⑤ 상위생활권 도출)
   - KPI 지표 계산 (일괄 산출 → 종합 리포트)
   - 3D 시각화

각 입력 칸의 [형식] 버튼은 필요한 필드와 예시를, [산식 보기]는 계산 방식을 보여 준다. 분석 기준과 지표 해석은 `mcp_server\guide\`의 문서를 참고한다.

## MCP 서버 (선택)

1. `mcp_server\설치_mcp.bat`을 실행한다. QGIS 파이썬에 `mcp` 패키지를 설치하고 Claude Desktop에 `krihs-s-sim`을 등록한다.
2. Claude Desktop은 트레이 아이콘까지 완전히 종료한 뒤 다시 연다. Claude Code는 아래 명령으로 등록한 뒤 새 세션을 연다.

```
claude mcp add -s user krihs-s-sim -- cmd /c "(이 폴더 경로)\mcp_server\run_server.bat"
```

MCP로 실행한 결과는 `mcp_server\분석결과\`에 모인다(처음 실행할 때 생김). 자세한 내용은 `mcp_server\README.md`를 본다.

## 자료 이용 시 유의

- `S-Sim_데이터팩\지역\(지역)\07_사용자자료`의 통행 행렬은 통신사 자료, 도로망은 KTDB 원자료 정제본이다. 외부에 배포할 때는 이 폴더를 빼고 사용자가 자기 자료를 지정한다.
- 생활편리성 KPI의 서비스권 반경·관리 대상 최소 배후인구 기본값(근린 1.5km·500명, 거점 3km·3,000명)은 예시 산출용 값으로 근거가 확정되지 않았다. 플러그인 KPI 공통 데이터에서 바꿀 수 있다.
- 플러그인을 고친 경우 이 묶음의 `KRIHS_S_Sim`과 QGIS에 설치된 플러그인을 함께 바꾼다(MCP 서버는 묶음 안의 플러그인을 쓴다).
